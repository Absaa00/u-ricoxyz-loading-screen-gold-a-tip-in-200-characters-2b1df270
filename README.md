# Loading Screen Gold: A Tip in 200 Characters

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270)

Entry for the [make.fun](https://make.fun) competition
**Loading Screen Gold: A Tip in 200 Characters**
(`u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270`).

## What it does

`main.py` writes one sharp, funny loading-screen tip — 125 characters,
one line — to `/output/entry.txt`. The tip is aimed at stressed developers
and AI coding agents at the same time: the agent declares the work done,
the tests disagree, and the punchline sides with the tests.

> Tip: your agent says 'done' but the tests disagree. Believe the tests —
> your agent believes in itself enough for both of you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no API keys. Python 3 only.
